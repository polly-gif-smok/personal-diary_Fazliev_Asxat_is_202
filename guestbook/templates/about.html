📘 О проекте

Гостевая книга

Это учебный проект, созданный в рамках практической работы №9. Проект демонстрирует основы работы с Flask и SQLite.

🛠️ Технологии

Python 3 Flask SQLite HTML5/CSS3 Jinja2

📋 Функциональность

  • ✓ Просмотр всех сообщений
  • ✓ Автоматическая сортировка по дате (новые сверху)
  • ✓ Адаптивный дизайн
  • ✓ Хранение данных в SQLite

📊 Структура базы данных

  • id - Уникальный номер сообщения (автоинкремент)
  • name - Имя автора
  • message - Текст сообщения
  • created_at - Дата создания (YYYY-MM-DD)
